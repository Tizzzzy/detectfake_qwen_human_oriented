# detectfake_qwen_human_oriented

A social-media text **AI-vs-Human** detection study. Participants read a short text plus an
explanation hint and decide whether it was written by a Human or generated by AI.

Stimuli (text + explanation hint) are served from `inference_raw_qwen_human_oriented.json`. The
architecture is `political_decision`'s: plain Flask + SQLite, no Vercel, no external
Postgres, deployable on any VPS via uWSGI/Gunicorn.

## How it works

- **Anonymous users** — identified by a `political_vsave` cookie (no login).
- **Data** lives in `inference_raw_qwen_human_oriented.json` at the repo root: a flat list of
  `{text_id, label, text, text_path, explanation}` records, loaded once at startup into memory — no
  migration step. A record's **position in the list** is its stable id
  (`stimulus_index`). `text_id` repeats in the file (the Reddit original and its AI
  rewrite share an id, with different text and different labels); **every row is served as
  its own trial**, so never key on `text_id` alone — use `stimulus_index`, or
  `(text_id, occurrence)`.
- **Balanced coverage** — each participant answers up to `TRIALS_PER_USER` distinct
  records, always served fewest-decisions-first, and no record is served more than
  `MAX_DECISIONS` times overall. There is no D1/D2 partition: the JSON has no split.
- **Resumable** — progress lives in the database, so closing and reopening the tab picks
  up at the next unanswered trial.
- **Database** is the SQLite file shared with `detectfake_rlvr`
  (`../detectfake_rlvr/webapp/detectfakesv3.db` by default; set `DETECTFAKE_DB_PATH` to point
  elsewhere). This app adds one table, `QwenHumanOrientedGuess` (`qwen_human_oriented_guess`,
  one row per answer), and never touches the existing tables.

## Run locally

```bash
pip install -r requirements.txt
python run.py          # serves on http://localhost:5002
```

`webapp/.secret_key` is created on first launch; the new table is created in the shared database.

## Deploy (uWSGI + nginx)

Edit the paths/user in `detectfake_qwen_human_oriented.ini`, then point uWSGI at it:

```bash
uwsgi --ini detectfake_qwen_human_oriented.ini
```

Or with gunicorn:

```bash
gunicorn -w 4 -b 0.0.0.0:5002 wsgi:application
```

## Configuration knobs (`webapp/text_routes.py`)

- `TRIALS_PER_USER` — trials per participant (default `50`); `None` = the whole pool.
- `MAX_DECISIONS` — stop serving a record once this many participants have judged it
  (default 5).
- `MAX_EXPLANATION_BULLETS` — max hint bullets shown per text; `None` (default) shows
  every bullet in the explanation.

## Data notes

`inference_raw_qwen_human_oriented.json` holds 750 records (383 Human, 367 AI), each with a
`text` and an `explanation`. `text_id`s can repeat (Reddit original vs. AI rewrite), so every row
is its own trial keyed by `stimulus_index`. `text_path` is stored alongside each answer.
